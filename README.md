**\~ Urban Bites - Restaurant Ordering System**



Urban Bites is a PHP and MySQL based restaurant ordering system.

Requirements



*\* XAMPP*

*\* PHP 8+*

*\* MySQL*

*\* Web browser*



**\~ Setup**



1\. Download or clone this repository.

2\. Move the project folder to:



C:\\xampp\\htdocs\\



3\. Open XAMPP and start:



Apache

MySQL



4\. Open phpMyAdmin:



http://localhost/phpmyadmin



5\. Create a new database for the project.

6\. Import the project's `.sql` file into the database.

7\. Open:



includes/config.php



and update the database details if needed:



$host = "localhost";

$user = "root";

$password = "";

$database = "your\_database\_name";



8\. Finally, open the project in your browser:



http://localhost/Restaurant-Ordering-System/
